# pragyamodi.github.io

My Website

## Content workflow (no backend)

Use Markdown files as the source of truth for updates:

- Blog posts: `content/blog/`
- Work experiences: `content/work-experiences/`
- Research experiences: `content/research-experiences/`
- Volunteering roles: `content/volunteering/`
- Education: `data/education.json`
- Talks: `data/talks.json`
- Awards: `data/awards.json`
- Certifications: `data/certifications.json`
- Manifest: `data/site.json`

Publishing remains static for now: edit content files first, then update the rendered HTML pages (`blog.html`, `cv.html`) as needed.
